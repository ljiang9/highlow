# highlow

终端高低牌猜大小游戏:看当前牌,猜下一张更大还是更小。

## 玩法

```bash
python -m highlow              # 交互游玩
python -m highlow --rounds 10  # 猜 10 局后结算
python -m highlow --auto 10000 --seed 1   # 中位数最优策略自动演示
```

- A 最大(算 14),2 最小;花色不影响大小。
- 猜对连胜 +1,猜错连胜清零;同点算**平局(push)**,连胜不清零、胜负都不计。
- 牌从一副 52 张里**不放回**依次抽,抽完自动重洗(已抽过的牌会影响后续概率,这是真实牌局的感觉)。
- 交互中输入 `q` 退出;非字母输入会提示重输。

## 中位数策略

`--auto` 用的最优策略很简单:当前点数 < 8 猜大,> 8 猜小,= 8 随便(期望相同)。
因为整副牌点数对称,猜"点数多的一侧"永远是最优的。理论胜率约 76%(平局不计,不放回抽牌比有放回略高),
`--auto 10000 --seed 1` 实测 76.05%。

## 已知局限

- 只做猜大小,不做德州/21 点等完整玩法。
- 交互是行输入模式,每步需回车。
- `--auto` 的策略只看当前牌点数,不记已出现的牌(记牌可再提一点胜率,没做)。
